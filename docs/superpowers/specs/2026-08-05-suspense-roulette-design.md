# 긴장감 강화 룰렛 설계

## 목표

기존 참가자·운전자·차량·좌석·방 배정 흐름은 유지하면서, 결과가 공개되는 순간의 긴장감과 참여감을 높인다.

## 핵심 경험

1. 운전자 선정은 생존자 룰렛으로 진행한다. 이름이 빠르게 순환하고, 탈락자가 한 명씩 공개되며 마지막 남은 인원이 운전자로 확정된다.
2. 좌석 배정은 10초 카운트다운과 함께 진행한다. 시간이 끝나면 현재 대상의 좌석이 강제 확정된다.
3. 게임 시작 때 운명 카드 3장을 무작위로 공개한다. 카드는 `운전자 교체`, `자리 보호`, `한 번 더 돌리기` 중에서 제공하며, 각 카드는 한 번만 사용할 수 있다.

## 상태와 안전장치

- 카드 사용 여부와 남은 카드 목록은 현재 게임 상태와 함께 저장한다.
- 운전자 교체는 아직 확정되지 않은 운전자 후보 사이에서만 허용한다.
- 자리 보호는 아직 배정되지 않은 참가자 한 명의 다음 좌석 배정을 잠근다.
- 한 번 더 돌리기는 현재 룰렛 결과를 무효화하고 같은 단계에서 다시 실행한다.
- 참가자 수가 부족하거나 차량 좌석이 모두 배정된 경우 카드는 비활성화하고 기존 검증 메시지를 보여준다.

## 화면 연출

- 운전자 단계에는 생존자 수, 현재 라운드, 긴장도 문구를 표시한다.
- 좌석 단계에는 큰 숫자 카운트다운, 진행 중인 참가자, 좌석 확정 애니메이션을 표시한다.
- 카드 사용과 운전자 확정에는 짧은 강조 색상, 흔들림, 결과 배너를 적용하되 접근성을 위해 텍스트 결과를 항상 함께 제공한다.
- 새로고침 후에도 진행 중인 단계와 카드 상태를 복원한다.

## 완료 기준

- 운전자 수를 여러 명으로 설정해도 생존자 룰렛이 중복 없이 완료된다.
- 카운트다운 종료 시 좌석이 중복 없이 확정된다.
- 카드 3장이 새 게임마다 초기화되고, 사용 후 재사용할 수 없다.
- 기존 차량별 좌석 규칙과 방 배정은 그대로 동작한다.
- 빌드, 순수 로직 테스트, 서버 렌더 테스트가 모두 통과한다.
