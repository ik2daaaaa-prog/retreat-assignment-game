# BMW Arcade Racer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a responsive top-down BMW arcade racing game with a real-model roster, powertrain filters, and a 3-lap race loop.

**Architecture:** Use the Sites starter with one React route. Keep the animated race loop in a canvas component and keep the garage/HUD controls in React state, communicating through typed callbacks and a small vehicle data module. Use localStorage only for the best lap/race time.

**Tech Stack:** React, TypeScript, Vite/vinext Sites starter, HTML Canvas, CSS, localStorage.

## Global Constraints

- Use original simplified vehicle silhouettes; do not copy official BMW logos or image assets.
- Show explicit Korean powertrain labels: 가솔린, 디젤, 전기.
- Support WASD, arrow keys, and touch controls.
- Use a single route and no backend.
- Validate with `npm run build` before publishing.

### Task 2: Add vehicle data and game page

**Files:**
- Create or modify: `app/page.tsx`
- Create or modify: `app/globals.css`
- Modify: `app/layout.tsx`

**Interfaces:**
- `Vehicle` contains `id`, `model`, `fuel`, `body`, `topSpeed`, `acceleration`, `handling`, `braking`, and `color`.
- `RaceState` contains `status`, `lap`, `totalLaps`, `elapsedMs`, `speed`, and `bestMs`.

- [ ] **Step 1: Define a roster covering petrol, diesel, and electric models**

Include iX1/iX2/iX3/iX, petrol and diesel X-series examples, 1/2/3/4/5/7/8 Series examples, Z4, M-series examples, and i4/i5/i7. Add filters for all, 가솔린, 디젤, 전기.

- [ ] **Step 2: Implement the garage panel**

Render filter chips, vehicle cards, selected-state styling, stat bars, and a start-race button with accessible labels.

- [ ] **Step 3: Implement the canvas race loop**

Draw a scrolling autobahn-inspired track, lane markings, traffic cars, the selected car, a finish/checkpoint indicator, and particles. Update position from keyboard/touch input, apply edge slowdown, detect traffic collision, count three laps, and emit telemetry to React.

- [ ] **Step 4: Implement HUD and result state**

Show lap, speed, timer, vehicle name, fuel tag, and best time. On finish, show final result and restart controls. Persist the best race time with a namespaced localStorage key.

- [ ] **Step 5: Implement responsive styling**

Use a two-column desktop layout and stacked mobile layout, with a touch D-pad over the canvas on narrow screens.

- [ ] **Step 6: Update metadata and remove starter-only UI**

Set the page title/description to the BMW game and remove temporary skeleton/preview imports and metadata.
